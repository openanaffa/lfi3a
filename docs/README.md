# LFI3A Documentation

Welcome to the documentation for **LFI3A**, a programming language based on Moroccan Arabic (Darija) syntax. This project aims to make programming more accessible and fun by using familiar linguistic concepts.

## Table of Contents

1. [Getting Started](lfi3a.md) - A quick introduction and installation guide.
2. [Language Syntax](syntax.md) - Detailed guide to LFI3A grammar, keywords, and control flow.
3. [Standard Library](standard_library.md) - Reference for built-in functions.
4. [Examples](../examples/) - Directory containing various sample programs.

## Key Features

- **Darija Syntax**: Write code using Moroccan Arabic keywords like `dir`, `ila`, `kteb`, etc.
- **Simple & Expressive**: Designed to be easy to read and write.
- **Cross-Editor Support**: Syntax highlighting available for [VS Code](../editors/vscode/) and [Notepad++](../editors/notepadplusplus/).

## Quick Example

```lfi3a
dir ism = "Oussama"
kteb("Salam", ism, "!")
```

For more details, see the [Syntax Guide](syntax.md).
